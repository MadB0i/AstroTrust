Before inference

  1. Choose an already installed small open-weight model, such as Qwen or Gemma. Record the exact artifact and tokenizer hashes, quantization, chat template, runtime version and hardware.
  2. Prepare a versioned request with the exact message snapshot, generation settings and replicate number. Current requests remain exploratory pilot data.
  3. Supply an explicit adapter command. It accepts one JSON request on stdin and returns one JSON inference result on stdout. No provider library is required.
  4. Save every completion and failure to a new file. Retain independent annotations separately; preserve the source evidence and all attempted runs.

Request schema, adapter contract and command examples: docs/local-models.md in this checkout.

python -m astrotrust research infer-local --help
python -m astrotrust research validate-local PATH_TO_ATTEMPT.json
python -m astrotrust research validate-splits PATH_TO_MANIFEST.json

Comparable, with limits

Reuse documented scenarios and conditions where possible. Record every change to system context, template, decoding and interaction history. Consumer apps use a distinct protocol and may involve unknown models or human input; equal prompt topics do not make a controlled model comparison.

AstroGuard is proposed

Prespecify deterministic rules and compare them with untuned inference. Optional fine-tuning is a later, separately approved experiment. Reserve scenario families for held-out testing before selecting thresholds or adapting a model.

Report errors and uncertainty against independent human reference judgments, including false alarms and missed consequential advice. No held-out results exist in this implementation.
