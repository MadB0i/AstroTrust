# Operational terminology

These are working definitions to refine through review, not settled psychological scales.

| Term | Working meaning |
| --- | --- |
| Sycophancy | A proposed pattern of undue alignment with an expressed user position when relevant evidence/context is fixed; requires contextual judgment, not agreement alone |
| Agreement | Endorsement of a proposition; distinguish it from acknowledging a person's feelings or repeating their question |
| Acknowledgment | Recognition of a stated belief/feeling without adopting its proposition in that passage |
| Astrological endorsement | Adoption of an astrological explanation as support for a proposition; attribution to a tradition alone does not establish adoption |
| Candidate sycophantic behaviour | A belief-conditioned shift toward the prior under fixed relevant context, subject to confound review; not a response-level binary truth label |
| Personalization | Adapting advice to a person; the current manipulation requests person-specific wording with identical supplied facts |
| Trust | A human attitude toward credibility or dependability in a stated context; response text alone does not measure it |
| Reliance | Using advice as a basis for choice/action; distinguish encouraged reliance in text from actual human behaviour |
| Belief-conditioned response | A response difference associated with a changed expressed prior under matched conditions |
| Astrological claim | A statement linking astrological concepts to an interpretation, expectation or recommended action, without implying its truth or falsity |
| Practical grounding | Use of situation-relevant considerations such as preparation, costs or consultation; its presence is not a universal quality verdict |
| Confidence | Expressed certainty in a response; separate from sampling temperature and from an experimentally manipulated confidence instruction |
| Source presentation | How authorship/authority is shown to a reader; a future experimental variable, absent from this instrument version |
| Stakes | Scenario-specific plausible consequences and reversibility of reliance; not an expected safety label |
| Neutral belief framing | No settled expressed prior on the target outcome, with the same astrology-related question |
| Synthetic | Intentionally invented context rather than participant data; still needs provenance and privacy review |
| Human reviewed | A recorded review status that must be supported by a review record; not a guarantee of equivalence or validity |
| BCAS / ADRS | Provisional constructs with no computed aggregate; the current handbook includes a draft ordinal reliance component without validated distances |
